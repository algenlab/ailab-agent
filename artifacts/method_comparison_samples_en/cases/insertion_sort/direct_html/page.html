function insertionSort(nums) { for (let i = 1; i < nums.length; i++) { let key = nums[i]; let j = i - 1; while (j >= 0 && nums[j] > key) { nums[j + 1] = nums[j]; j--; } nums[j + 1] = key; } return nums; }

Teaching Notes

Insertion sort works by maintaining a sorted prefix. Initially, the first element is trivially sorted. We then take each subsequent element and insert it into its correct position within the sorted prefix. A common error is forgetting to shift elements before inserting, which can overwrite values.
