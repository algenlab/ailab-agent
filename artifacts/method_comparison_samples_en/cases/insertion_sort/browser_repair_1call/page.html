Insertion Sort

Sort song favorability scores from lowest to highest using the insertion sort method.

Progress: sorting... O(n²) time | O(1) space

Algorithm Code

function insertionSort(nums) {    for (let i = 1; i < nums.length; i++) {        let key = nums[i];        let j = i - 1;        while (j >= 0 && nums[j] > key) {            nums[j + 1] = nums[j];            j--;        }        nums[j + 1] = key;    }    return nums;}
