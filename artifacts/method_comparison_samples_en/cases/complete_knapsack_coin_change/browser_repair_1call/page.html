Algorithm Code
function coinChange(coins, amount) {    const dp = new Array(amount + 1).fill(Infinity);    dp[0] = 0;    for (let c = 1; c <= amount; c++) {        for (const coin of coins) {            if (coin <= c) {                dp[c] = Math.min(dp[c], dp[c - coin] + 1);            }        }    }    return dp[amount] === Infinity ? -1 : dp[amount];}

Teaching Notes
We initialize the dp array where dp[c] represents the minimum coins needed for amount c. dp[0] = 0 because zero coins are needed to make amount 0. All other entries start at Infinity (unreachable).
