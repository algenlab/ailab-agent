Kth Largest Element in an Array

Min-Heap Streaming Algorithm — Process ratings one by one, maintain a heap of capacity k

K-th largest: — Strategy: Maintain a min-heap of size k; its top is the k-th largest element seen so far. 5

Algorithm Code

def findKthLargest(nums, k):    heap = []            # min-heap of capacity k    for num in nums:        if len(heap) < k:            heap.push(num)   # heap not full, add directly        elif num > heap[0]:            heap.pop()        # remove current k-th largest            heap.push(num)    # insert larger element        # else: num is too small, ignore it    return heap[0]        # top of min-heap is k-th largest

Teaching Explanation

The min-heap of capacity k maintains the k largest elements seen so far. The smallest element in this heap (the top) is the k-th largest overall. Initially, the heap is empty.
