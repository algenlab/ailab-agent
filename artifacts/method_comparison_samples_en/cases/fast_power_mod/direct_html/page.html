Algorithm Implementation (JavaScript)
function fastPower(base, exponent, mod) { let result = 1; base = base % mod; // reduce base modulo mod while (exponent > 0) { if (exponent & 1) { // check LSB result = (result * base) % mod; } base = (base * base) % mod; // square the base exponent = exponent >> 1; // right shift } return result; }

Teaching Notes

We start by setting result = 1 and reducing base modulo mod. The exponent 5 in binary is 101. For each bit (from least significant to most), we square the base and multiply the result when the bit is 1.
