Two Sum

Order Fulfillment System — Hash Table / Map Strategy

Expected output: [0, 1] Strategy: Hash table lookup for complement

Problem: In an order fulfillment system, nums[i] represents the quantity of goods that can be directly picked from the i-th slot, and the order still lacks target units of the same goods. Find two different slots such that the sum of their quantities equals exactly target, and return their 0-based indices; if no such slots exist, return an empty array.

Input: nums = [2, 7, 11, 15], target = 9  |  Final answer: [0, 1]

Algorithm Code

function twoSum(nums, target) { const map = new Map(); for (let i = 0; i < nums.length; i++) { const complement = target - nums[i]; if (map.has(complement)) { return [map.get(complement), i]; } map.set(nums[i], i); } return []; }

We begin by creating an empty hash map to store values we have seen, mapping each value to its index. Then we start traversing the array from index 0.

Why this works: A hash map provides O(1) lookup. For each element, we compute its complement (target - current value) and check if we have already seen that complement. If we have, we found our pair. This turns the naive O(n²) approach into O(n) time.
