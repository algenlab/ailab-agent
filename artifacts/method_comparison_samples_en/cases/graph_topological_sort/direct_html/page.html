Topological Sort

Course dependency resolution using Kahn's BFS-based algorithm

Expected Output

["A", "B", "C", "D"]

Algorithm Strategy

Maintain indegree table and queue of zero-indegree nodes; each time a node is popped, delete its outgoing edges.

Pseudocode — Kahn's Algorithm

function topologicalSort(graph):    indegree = map each node to 0    for each node u in graph:        for each v in graph[u]:            indegree[v] += 1        queue = empty queue    for each node u in graph:        if indegree[u] == 0:            queue.enqueue(u)        result = []    while queue is not empty:        u = queue.dequeue()        result.append(u)        for each v in graph[u]:            indegree[v] -= 1            if indegree[v] == 0:                queue.enqueue(v)        return result
