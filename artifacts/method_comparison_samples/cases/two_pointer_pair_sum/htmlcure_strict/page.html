有序数组两数之和

LeetCode 167 风格 · 左右双指针 · 升序数组 nums = [1, 2, 4, 6, 10] · target = 8

✅ 结果：[1, 3] 💡 nums[1]=2 + nums[3]=6 = 8 [1, 3]
1 / 5 🔧 初始化
📝 算法代码
function twoSum(nums, target) { let L = 0, R = nums.length - 1; while (L < R) { let sum = nums[L] + nums[R]; if (sum === target) { return [L, R]; } else if (sum < target) { L++; } else { R--; } } return []; }

👨‍🏫 教学讲解
为什么用双指针？因为数组是升序排列的。左指针指向最小元素，右指针指向最大元素。计算两数之和后，根据与 target 的比较，可以确定性地决定移动哪个指针——这是双指针法的核心优势。
