📜 算法实现
def dijkstra(graph, start):    dist = {node: INF for node in graph}    dist[start] = 0    heap = [(0, start)]        # (距离, 节点)    visited = set()    while heap:        d, u = pop_min(heap)    # 取最小距离节点        if u in visited: continue        visited.add(u)        for v, w in graph[u]:   # 松弛邻居            if dist[v] > d + w:                dist[v] = d + w                heap.append((dist[v], v))    return dist

👨‍🏫 教学讲解

Dijkstra算法的核心思想：从起点开始，每次从堆中取出当前距离最小的未访问节点，然后松弛它的所有邻居。初始化时，只有起点A的距离为0，其他节点距离设为无穷大。将(0, A)加入最小堆。

📝 步骤证据

operation: initialize targets: all nodes before: dist全为INF after: dist[A]=0, heap=[(0,A)], visited={} 不变量: dist[start]始终为0，堆始终按距离排序
