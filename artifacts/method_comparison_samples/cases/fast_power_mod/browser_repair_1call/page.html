📜 算法代码
function solve(base, exponent, mod) { let result = 1; base = base % mod; while (exponent > 0) { if (exponent % 2 === 1) result = (result * base) % mod; base = (base * base) % mod; exponent = Math.floor(exponent / 2); } return result; }

💡 教学讲解
快速幂的核心思想是将指数拆成二进制表示。5 的二进制是 101，即 5=4+1=2²+2⁰。我们初始化 result=1 作为乘法起点，base 存储当前底数（会不断平方），exponent 记录剩余指数。循环检查 exponent 的二进制最低位，遇到 1 就将当前 base 乘入 result。
