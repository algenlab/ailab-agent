def reverseList(head): prev = None # 前驱指针 current = head # 当前指针 while current: # 遍历链表 next = current.next # 暂存后继 current.next = prev # 反转指向 prev = current # 前驱前进 current = next # 当前前进 return prev # 返回新头

📖 教学讲解

在开始反转之前，我们需要两个指针：prev（前驱节点）初始为 null，current（当前节点）指向链表头部。反转的核心思想是逐个改变每个节点的 next 方向，让它指向前一个节点。
