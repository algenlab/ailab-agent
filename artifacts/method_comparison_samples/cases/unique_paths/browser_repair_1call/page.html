策略：dp[i][j] = dp[i-1][j] + dp[i][j-1]
每个格子的路径数 = 上方路径数 + 左侧路径数

算法伪代码

function uniquePaths(m, n): // 创建 m×n 的二维DP数组 dp = 创建 m 行 n 列的二维数组 // 初始化第一行和第一列为 1 for i = 0 to m-1: dp[i][0] = 1 for j = 0 to n-1: dp[0][j] = 1 // 按行填充DP表 for i = 1 to m-1: for j = 1 to n-1: dp[i][j] = dp[i-1][j] + dp[i][j-1] // 返回右下角结果 return dp[m-1][n-1]
