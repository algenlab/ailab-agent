Trie 前缀计数
插入单词 + 沿前缀路径统计匹配数量
🎯 最终答案 3 前缀 "ap" 匹配 3 个单词：apple、app、ape
📜 算法代码
function solve(words, prefix) {
  const root = new TrieNode();
  // 阶段1：插入所有单词
  for (const word of words) {
    let node = root;
    for (const ch of word) {
      if (!node.children[ch]) {
        node.children[ch] = new TrieNode();
      }
      node = node.children[ch];
      node.count++;
    }
  }
  // 阶段2：查询前缀
  let node = root;
  for (const ch of prefix) {
    if (!node.children[ch]) return 0;
    node = node.children[ch];
  }
  return node.count;
}

    步骤 1：初始化 创建根节点
    创建空的 Trie 根节点，准备插入所有单词。
    Trie（前缀树）的根节点不存储任何字符，它只作为树的入口。每个节点维护一个 count 表示经过该节点的单词数量，以及一个 children 映射表指向子节点。初始化时根节点的 count=0，children 为空。
