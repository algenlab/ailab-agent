# 黄金样例：BFS 最短层数

## 输入

```json
{"graph": {"A": ["B", "C"], "B": ["D"], "C": ["D"], "D": []}, "start": "A"}
```

expected output：

```json
{"A": 0, "B": 1, "C": 1, "D": 2}
```

## 关键步骤

- 起点入队，距离为 0。
- 每次弹出队首节点。
- 检查当前节点邻居。
- 首次访问邻居时写入距离并入队。
- 队列为空后返回距离表。

## 视觉重点

- 主原语：`graph`
- 辅助原语：`queue`、`map`
- 关键对象：`graph`、`queue`、`dist`、`node:A`、`node:B`、`edge:A->B`
- 关键 deps：`node:A`、`edge:A->B`、`edge:A->C`、`node:B`、`edge:B->D`
- 当前出队节点。
- 当前检查边。
- 新访问节点。
- 队列内容。
- 距离表。

## 教学解释

关键 teaching 字段：`what`、`why`、`formula`、`invariant`。

BFS 按层扩展。一个节点第一次被访问时，当前路径就是从起点到它的最短边数。

## 验收标准

- 每个首次访问节点都必须有父节点 deps。
- 距离必须等于父节点距离 + 1。
- 页面能同时看到图和队列。
