# 黄金样例：稀疏表区间最小值

## 输入

```json
{"nums": [5, 2, 7, 3, 6, 1], "query": [1, 4]}
```

expected output：

```json
2
```

## 视觉原语

- 主视图使用 `matrix` 展示 `st`。
- `st[k][i]` 表示从 `i` 开始、长度为 `2^k` 的区间最小值。
- `log` 用数组展示每个长度对应的最大幂。
- 查询参数使用 `query[0]`、`query[1]`。

## Trace 要点

- 不使用 `range:` target。
- 预处理时，`st[k][i]` 依赖 `st[k-1][i]` 和 `st[k-1][i+2^(k-1)]`。
- 查询时选择 `k = log[r-l+1]`。
- 区间最小值由两个可重叠区间 `st[k][l]` 和 `st[k][r-2^k+1]` 合并。

## 教学解释

稀疏表利用幂长区间复用结果。对幂等的最小值操作，两个重叠区间覆盖原查询区间也不会影响答案。
