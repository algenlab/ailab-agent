# 黄金样例：不同路径

## 输入

```json
{"m": 3, "n": 7}
```

expected output：

```json
28
```

## 关键步骤

- 初始化 `dp` 表，第一行和第一列为 1。
- 逐格填充内部单元。
- 每个内部单元满足 `dp[i][j] = dp[i-1][j] + dp[i][j-1]`。
- 返回右下角 `dp[m-1][n-1]`。

## 视觉重点

- 主原语：`matrix`
- 辅助原语：无
- 关键对象：`dp`、`dp[1][1]`、`dp[0][1]`、`dp[1][0]`
- 关键 deps：`dp[0][1]`、`dp[1][0]`、`dp[1][6]`、`dp[2][5]`
- 当前格高亮。
- 上方和左方依赖格高亮。
- 箭头从依赖格指向当前格。
- 显示当前公式和值代入过程。

## 教学解释

关键 teaching 字段：`what`、`why`、`formula`、`invariant`。

到达当前格子只能来自上方或左方，因此路径数等于两个依赖格路径数之和。处理当前格时，它上方和左侧的格子已经被正确计算。

## 验收标准

- 小规模输入必须完整记录每个内部格 `set`。
- 每个 `set` 事件必须有两个 deps，边界单行 / 单列除外。
- 页面能显示公式、依赖对象和过程校验证据。
