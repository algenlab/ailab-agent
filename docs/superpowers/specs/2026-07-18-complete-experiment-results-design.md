# 完整实验结果总账设计

## 目标

将所有已经形成冻结汇总结果的实验族统一写入 `docs/EXPERIMENT_RESULTS.md`，保留当前版本“核心结果前置、指标首次出现即解释、表格后可直接读懂”的优点，并将理论定向实验组织为独立章节。

## 收录边界

- 收录有冻结 JSON、汇总报告或证据账本条目的主实验、先导实验、外部 baseline、消融、稳健性、预算、理论审计、教学与视觉代理评价。
- 同一实验的 shard、resume、失败任务补跑和 debug probe 不单独作为实验行；它们合并到所属实验，并在证据索引中保留路径。
- 尚无真人标签或参与者数据的项目只列状态，不填写结果。
- 数字冲突时依次采用冻结机器结果、`latex/evidence-ledger.md`、本汇总文档、历史报告。

## 文档结构

1. 核心结果表。
2. 阅读口径、指标和统计术语。
3. Benchmark 构建、数据扩充与先导实验。
4. 主实验和比较方法。
5. 外部 baseline 与传统系统能力审计。
6. 消融与组件必要性。
7. 跨输入、held-out 和 long-trace。
8. 跨模型、候选预算、修复预算和成本。
9. 理论定向实验专章。
10. 教学与视觉代理评价。
11. Judge 稳健性、人工数据状态和历史实验索引。
12. 结论边界与原始证据索引。

## 理论定向实验专章

理论章节按“理论主张—实验检查对象—直接结果—解释边界”组织，至少包含：

- Local Resume vs Global Restart：端到端结果、配对成功数、token 分解、有限预算拟合和 Flat Final-Only 边界；
- Trace→Scene→Runtime 语义保持和确定性；
- Nested contract cumulative survival 与 conditional survival，覆盖机器报告中的 11 个方法/模型条件；
- Semantic mutation 的拒绝与接受类别；
- Teaching overlay 的合法替换、非法写入和跨模型复用；
- 240 页、24,000 序列、1,561,298 动作的 noninterference stress test。

## 可读性规则

- 关键结果仍放在第 0 节，读者不需要先读完整文档。
- 指标第一次出现时给出通俗定义和“不代表什么”。
- 宽表使用统一缩写，并在表前解释 C1—C6、Primary、Final 等术语。
- 每张主要表后保留一段“结果直读”；理论与代理评价另加“解释边界”。
- 历史先导实验与正式冻结结果明确分开，避免旧数字覆盖主结论。

## 验证要求

- 所有核心分母和数字与机器 JSON、evidence ledger 一致。
- 所有本地证据路径存在。
- Markdown 表格列数一致，标题层级连续，反引号与文件结尾正常。
- 文档必须能定位全部已完成实验族，并明确未完成真人实验。
