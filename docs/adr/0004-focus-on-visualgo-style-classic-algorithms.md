# ADR-0004: V1 聚焦 VisuAlgo-style 经典算法题

## Context

如果系统试图覆盖任意代码、任意网页和任意算法，会导致 schema、validator、renderer 和 benchmark 都无法收敛。

## Decision

V1 聚焦经典算法题和教学型可视化，尽可能覆盖适合课堂讲解和过程校验的经典算法族。

优先覆盖：

- 数组、前缀和、差分、二分、双指针、滑动窗口。
- 排序、选择、栈、队列、单调结构、哈希表、链表。
- 字符串匹配、Trie、KMP、Rabin-Karp、Z Algorithm、Manacher。
- 动态规划：一维、二维、背包、区间、树形、状态压缩、数位。
- 贪心、分治、回溯、递归树、位运算、数学与数论。
- 图：BFS、DFS、拓扑排序、连通性、最短路、MST、匹配和网络流入门。
- 树、堆、并查集、线段树、树状数组、稀疏表。
- 计算几何：方向判断、线段相交、凸包、扫描线。

覆盖策略是先覆盖每类算法的教学代表题和可视化模式，再逐步扩展变体。

## Consequences

好处：

- 产品目标清晰。
- 视觉原语可以复用。
- process invariant validator 能针对算法族增强。
- benchmark 可以形成可复现评估闭环。

代价：

- 暂不追求全 LeetCode 覆盖，但经典算法族清单要尽量完整。
- 对任意代码调试场景支持有限。
- 复杂算法族需要分阶段扩展。
