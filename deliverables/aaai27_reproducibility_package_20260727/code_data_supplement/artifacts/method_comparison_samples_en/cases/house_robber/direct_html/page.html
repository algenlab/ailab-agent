Step 1: Problem Setup initialize
We have 5 houses with cash amounts [2, 7, 9, 3, 1]. Adjacent houses cannot both be robbed. We will build a DP table where dp[i] stores the maximum profit considering houses 0 through i.

Pseudocode

function rob(nums):    n = length(nums)    if n == 0: return 0    if n == 1: return nums[0]    dp[0] = nums[0]    dp[1] = max(nums[0], nums[1])    for i = 2 to n-1:        dp[i] = max(dp[i-1], dp[i-2] + nums[i])    return dp[n-1]

Teaching & Explanation

We start by understanding the problem constraints. The thief cannot rob two adjacent houses because of connected alarms. We need to find the subset of non-adjacent houses that yields the maximum total cash. Dynamic programming will help us build the solution incrementally. Each dp[i] represents the best profit we can achieve using only the first i+1 houses (indices 0 through i).
