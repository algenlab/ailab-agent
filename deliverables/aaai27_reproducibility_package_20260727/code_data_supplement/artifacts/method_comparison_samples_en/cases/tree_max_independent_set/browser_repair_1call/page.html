What is happening?

We initialize the Tree DP. Each node will get two values: dp_take (maximum value achievable from the subtree rooted at this node, assuming this node is selected) and dp_skip (assuming this node is not selected). The post-order traversal will process leaves first, then move upward. For a leaf, dp_take = its own value and dp_skip = 0.

Invariant: Every node's dp_take and dp_skip represent the optimal value for its entire subtree under the respective selection constraint.
