Daily Temperatures Monotonic Stack Stack / Queue
Greenhouse ventilation scheduling: find days until a warmer temperature occurs.
Expected Output
[1, 1, 4, 2, 1, 1, 0, 0]
Strategy
Maintain a monotonic decreasing stack of indices. When a higher temperature arrives, pop the stack and record the day difference as the answer for each popped index.
Algorithm Implementation
function dailyTemperatures(temperatures) { let n = temperatures.length; let answer = new Array(n).fill(0); let stack = []; for (let i = 0; i < n; i++) { while (stack.length > 0 && temperatures[i] > temperatures[stack[stack.length - 1]]) { let prevIndex = stack.pop(); answer[prevIndex] = i - prevIndex; } stack.push(i); } return answer; }
