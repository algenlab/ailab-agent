Daily Temperatures

Greenhouse ventilation scheduling using a monotonic decreasing stack. Find how many days until a warmer temperature for each forecast day.

We use a monotonic decreasing stack to track indices of days waiting for a warmer temperature. The stack will always contain indices with temperatures in strictly decreasing order (from bottom to top). When a warmer day arrives, it resolves all colder days on the stack at once — this is the key efficiency insight.
