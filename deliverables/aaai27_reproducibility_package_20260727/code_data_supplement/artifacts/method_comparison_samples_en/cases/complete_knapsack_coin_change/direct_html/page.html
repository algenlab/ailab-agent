Complete Knapsack Coin Change

DP Core Extension – Minimum coins with unlimited supply (coins = [1, 2, 5], amount = 11)

Minimum coins needed: 3
Coin combination: 5 + 5 + 1 = 11 (3 coins)
3

Algorithm Code

function coinChange(coins, amount) {
  let dp = new Array(amount + 1).fill(Infinity);
  dp[0] = 0;
  for (let coin of coins) {
    for (let i = coin; i <= amount; i++) {
      dp[i] = Math.min(dp[i], dp[i - coin] + 1);
    }
  }
  return dp[amount] === Infinity ? -1 : dp[amount];
}

Teaching Notes

We initialize the DP table. dp[c] represents the minimum number of coins needed to make amount c. dp[0] = 0 because zero coins make amount 0. All other amounts start as Infinity (unreachable).
