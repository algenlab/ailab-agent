\begin{abstract}
This supplement documents protocols, secondary results, artifact provenance, and reproducibility boundaries; it adds no primary claim. Its finite executable audits do not establish universal guarantees, \localresume{} is not fully checkpointed recovery, and all human studies remain incomplete.
\end{abstract}

\section{Supplement Scope and Reading Guide}

The main paper contains every result required to evaluate the contribution within the seven-page technical-content limit. This document expands the measurement protocol, reports secondary tables, records artifact provenance, and presents the real generated interface. Review of this supplement is not necessary to interpret the primary claims. Where an audit set contains a targeted retry, we identify it explicitly rather than converting it into an original generation success.

\section{Machine OK Protocol and Artifact Provenance}

\subsection{Decision Rule}

For each page, the browser harness records nine booleans: page load, visible-answer match, reachable interaction, correct feedback, wrong feedback, hint behavior, answer-reveal behavior, learning-log behavior, and mutation-free teaching behavior. A page is \machineok{} only if all nine are true. Correct and wrong feedback are tested using distinct submitted values. Hint and answer-reveal controls must change their associated pedagogical state, and the learning log must record the tested event. Pure teaching actions must preserve the canonical algorithm state, current step, and artifact hash. Navigation may change the step only to a verified target frame. External requests are blocked during the release audit.

\subsection{Generation and Statistical Boundaries}

The main comparison uses sample index 0 for each of 200 tasks, preventing tasks with more stored inputs from receiving greater weight. The full benchmark contains 646 samples. The original \system{} condition uses DeepSeek-V4-Pro; the uniform fixed-budget study uses DeepSeek-V4-Flash, GLM-5.2, and Kimi-K2.5. Direct HTML receives the concrete input and expected answer and is explicitly asked to generate the complete interaction suite. The main selected-final \system{} set contains 195 primary successes plus five recorded targeted retries; it must not be described as 200 first-pass successes.

McNemar tests use paired task-level binary outcomes. Paired bootstrap confidence intervals resample tasks, not frames, actions, or individual metric checks. Holm correction applies to test families, and paired ordinal or continuous secondary scores use Wilcoxon signed-rank tests where appropriate. Frame and action totals describe implementation coverage and are not treated as independent inferential samples. A nonsignificant result is not evidence of equivalence.

\section{Nested Contract Survival}

The nested levels are: C1 visible-answer match; C2 C1 plus page load; C3 C2 plus reachable interaction; C4 C3 plus correct and wrong feedback; C5 C4 plus hint, answer reveal, and learning log; and C6 C5 plus mutation-free teaching behavior. Values in Table~\ref{tab:nested-survival} are cumulative. Conditional survival at level $i$ is the cumulative C$i$ count divided by the cumulative C$(i-1)$ count; no independence assumption is made.

The repeated pattern is not that all contracts are independent. Rather, monolithic pages continue to lose surviving artifacts at load, interaction, and feedback boundaries, while factored pages that pass semantic validation retain most downstream mass.

\section{Local Resume Versus Global Restart}

Local keeps the current solution specification, repairs it, then reruns materialization and teaching. Browser evaluation blocks external resources. The screenshot in Figure~\ref{fig:system-ui} is produced by a scripted viewport, timeline selection, and hint interaction. Selected-final reporting preserves retry provenance rather than treating every page as a first-pass generation.

\subsection{Prepared but Unlabeled Human Protocols}

No protocol below has completed labels or participants:
\begin{itemize}
  \item \textbf{Machine-evaluator calibration:} 30 tasks $\times$ 4 methods, or 120 blind pages, prepared for two human annotators; no precision or recall result exists.
  \item \textbf{Independent trace audit:} 40 tasks across 23 families prepared for two reviewers; no critical-error rate exists.
  \item \textbf{Expert comparison:} 3 experts $\times$ 30 pairs planned; there is no preference or usability result.
  \item \textbf{Student study:} 24 students $\times$ 12 trials planned, subject to any required ethics process; there is no learning outcome.
\end{itemize}
These protocols are future evaluation infrastructure. No missing human labels are imputed, and no learning, retention, transfer, expert-preference, or human-calibrated trace-correctness claim is made.
